# Travelgram

## Acessar no navegador

**[Abrir o projeto](https://mateushdsouza.github.io/projeto-travelgram/)**

Não é necessário clonar o repositório, instalar ferramentas ou baixar arquivos para visualizar a versão publicada.


Página estática de um perfil de viagens, com apresentação, informações do perfil e galeria de fotografias.

## Tecnologias

HTML e CSS, com Flexbox.

## Desenvolvimento local (opcional)

```sh
git clone https://github.com/mateushdsouza/projeto-travelgram.git
cd projeto-travelgram
```

Abra [index.html](index.html) no navegador. Não é necessário instalar dependências. Fontes externas, quando utilizadas, precisam de internet.

## Organização

- [index.html](index.html): estrutura da página.
- [styles/](styles/): estilos.
- [assets/](assets/): imagens e ícones.

## Estado atual e limitações

Não é uma rede social: os dados são fixos e não há cadastro ou envio de fotos.

## Aprendizado

Estruturação de conteúdo em HTML, organização de estilos e composição visual. A presença de uma interface não representa um serviço completo em produção.
